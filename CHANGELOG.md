# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
SeedSleuth uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-07-30

### Added

- Shell-free JavaScript-module and external-command generator adapters.
- Bounded worker execution, timeouts, world-size limits, and repeated-seed
  determinism checks.
- Count, reachability, path-distance, connectivity, metric, border, and
  minimum-separation contracts.
- Grid metrics, robust median/MAD outlier detection, and deterministic
  fingerprints.
- Offline JSON, HTML, JUnit, and Markdown evidence reports.
- A real rooms-and-corridors demo with healthy and defective connector modes.
- A dependency-free CLI, reusable library API, and GitHub Action.
- Cross-platform CI, CodeQL, Pages, release packaging, checksum, clean-install,
  and reproducibility gates.
